# 领域术语

> 接入项目时填写稳定术语。使用虚构或抽象示例，避免公司、产品、客户和内部系统名称。

| 术语 | 含义 | 易混淆边界 | 权威事实源 |
|---|---|---|---|
| Harness | 约束、上下文、工作流与反馈系统 | 不是单一 Prompt | `.harness/README.md` |
| Agent | 可自主选择步骤或工具的执行单元 | 不等于普通确定性函数 | 项目架构文档 |
| Skill | 面向一类任务的结构化工作流 | 不等于业务功能本身 | `.harness/skills/` |
| | | | |

术语变化时，优先更新权威业务或架构文档，再同步本页。
