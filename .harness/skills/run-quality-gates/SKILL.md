# Run Quality Gates

## 选择门禁

| 变更 | 最低门禁 | 按风险追加 |
|---|---|---|
| 局部确定性逻辑 | 专项测试、静态检查 | 快速/全量回归 |
| 接口或用户路径 | 专项与集成测试 | 端到端、兼容性 |
| 数据或状态 | 约束、迁移、事务测试 | 并发、回滚、升级 |
| Agent/Prompt | mock 行为测试 | 小规模评估、路由回归 |
| 配置或部署 | 只读健康检查 | 隔离启动、发布 smoke |

## 步骤

1. 读取变更档案、测试规范和环境命令表。
2. 确认正确工作目录、运行时和隔离边界。
3. 从最快、最相关的门禁开始，逐层扩大。
4. 对失败分类：产品缺陷、测试缺陷、环境、依赖、权限、预算或已知问题。
5. 不安装依赖或修改用户环境来制造通过。
6. 记录命令、退出状态、通过/失败/跳过数量和未验证边界。

只有必要门禁通过且失败得到解释时，才建议变更进入完成状态。
