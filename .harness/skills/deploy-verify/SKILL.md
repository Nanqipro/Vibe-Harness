# Deploy Verify

## 授权边界

- 默认执行只读检查。
- 共享环境写入、数据库变更、滚动部署、外部通知和真实流量操作需要明确授权。
- 不输出凭据、认证材料、内部地址、个人数据或完整内部响应。

## 发布前

1. 确认目标环境、版本、范围、负责人和停止条件。
2. 检查工作树、构建产物、配置覆盖、schema 前置条件和回滚材料。
3. 运行项目环境文档规定的只读健康检查和质量门禁。
4. 确认日志、指标、告警和关联标识可用。

## 启动与 smoke

- 先验证进程、端口或平台健康，再验证关键接口和 Agent 路径。
- 测试鉴权、错误处理、流式完成/异常、外部依赖降级和关键读写。
- 使用虚构或脱敏输入，限制请求量、预算、超时与重试。

## 发布后

- 对照基线检查错误率、延迟、资源、队列和业务指标。
- 验证版本与配置实际生效，记录时间窗口和证据。
- 触发停止条件时执行已批准回滚，不临场扩大操作权限。

## 输出

给出目标、已执行检查、结果、未验证边界、观察窗口、回滚条件和最终建议。没有真实执行的步骤只能标记为待验证。
